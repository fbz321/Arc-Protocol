# 魔导协议 · Arc Protocol

> 把「训练 → 评估 → 迭代」做成一款竖屏策略养成游戏。

《魔导协议》是一款以 AI 后训练为主题的 Web 游戏原型。你可以调整日志配比、选择核心指令，生成训练候选，再把选中的结果应用到当前协议，通过自动战斗验证方案。卡关时，评估报告会提供下一轮调优的参考。

**当前版本：v0.1.0 · 预览版**。这是可试玩的数值与交互原型，不是完整商业游戏。

[下载版本](https://github.com/fbz321/Arc-Protocol/releases) · [更新记录](CHANGELOG.md) · [完整策划案](https://github.com/fbz321/Arc-Protocol/blob/main/demo.md)

## 快速开始

### 直接试玩

1. 从 Releases 下载 `Arc-Protocol-v0.1.0.zip`，或下载本仓库源码。
2. 解压后，用现代浏览器打开 `index.html`。
3. 手机建议竖屏体验；桌面以居中的窄屏游戏区域展示。

游戏不需要安装依赖、构建、注册账号或填写 API Key。HTML、CSS、JavaScript 均在单个页面内，下载后可离线运行。

> **进度仅存在于当前页面内存中，刷新或关闭页面会重置。** 日志池的时间累计是原型模拟，不支持关闭页面后的跨会话离线结算。

### 本地开发

```bash
git clone https://github.com/fbz321/Arc-Protocol.git
cd Arc-Protocol
```

直接打开 `index.html` 即可。若需要通过 HTTP 访问，且已安装 Python 3，也可以在项目根目录运行：

```bash
python -m http.server 8000
```

随后打开 `http://localhost:8000`。此方式仅用于本地预览，不是生产部署配置。

## 怎么玩

1. **观察作战**：页面载入后自动演算，查看敌方、队友血量和战斗战报。
2. **配置训练**：在「训练」中选择基模、训练方式、轮次和 Benchmark。
3. **调整配方**：分配 Bulwark（壁垒）、Weaver（源织）、Conductor（谐振）的日志比例，选择破阵、护卫或共鸣指令。
4. **确认收益**：查看预计写入、日志消耗、算力消耗与剩余容量，再执行训练。
5. **应用候选**：执行训练会消耗资源并生成候选，**不会自动替换当前能力向量**。到「仓库」中选择训练结果，点击「应用到当前协议」，再观察战斗表现。
6. **评估迭代**：失败后查看评估报告，返回训练修改方案；在「任务」中手动领取已完成任务的奖励。

协议深度可手动调整，用于测试不同容量和对手；当前不是完整的章节解锁流程。

## 已实现内容

| 模块 | 当前原型功能 |
| --- | --- |
| 作战 | 三人自动战斗、攻击与命中特效、战报、失败评估、重新演算 |
| 仓库 | DeepSeek / Kimi / MiniMax 展示，训练候选查看与手动应用 |
| 训练 | SFT / DPO / RFT、轮次与 Benchmark 配置、日志配比、核心指令、收益预览、五维成长展示 |
| 任务 | 一次性任务、手动领取奖励、新手引导回看与重播 |
| 界面 | 竖屏战场、四栏底部导航、可折叠详情、键盘焦点、减少动态效果支持 |
| 蓝图 | 导出当前协议配置为 JSON，尝试复制到剪贴板 |

基模名称、训练方式和 Benchmark 是游戏内设定与数值模拟；**不会调用真实模型 API，也不会执行真实机器学习训练**。

## 已知限制

- 没有存档、云同步、账号系统或服务端。
- 没有蓝图导入；蓝图导出不等于存档。
- 浏览器的剪贴板权限可能影响蓝图复制。
- 策划案中的抽取、五人阵容、完整地图等内容不代表已实现功能，请以当前页面为准。
- 尚未提供许可证文件；请勿默认按 MIT 等开源许可证使用。

## 验证

安装支持 `node --test` 的 Node.js 后，在项目根目录运行：

```bash
node --test tests/*.test.mjs
```

现有测试包含界面契约检查及部分运行时断言，但不是完整的浏览器端到端测试。布局或交互变更后仍需在浏览器中检查手机和桌面视口。
