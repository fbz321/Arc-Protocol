# 魔导协议竖屏界面设计

日期：2026-10-02
用户已确认：极简魔导终端、敌上我下的战场、底部四栏导航；2026-10-02 指示开始实施。

## 范围
保持单文件、离线即玩，无外部依赖，不改变数值、训练候选选择、任务奖励和战斗计时。

## 视觉与布局
- 以 390px 竖屏为主，320px 至桌面均不横向溢出；桌面居中 480px 游戏区域。
- 石墨底 #101719、面板 #172123、骨白 #e7eee8、青绿 #91d6c0、琥珀 #d5b47b；系统中文无衬线，数据等宽。
- 紧凑品牌和协议深度设置；默认只显示日志、算力，资源详情可展开，保留所有原有资源节点。
- 四个带图标的固定底部导航按钮，留安全区和正文底部空间。
- 作战区按敌方、协议法阵、我方三人排列。几何法阵是唯一视觉签名，不引入图片或角色美术。
- 战报默认折叠，摘要随日志更新，完整战报、清空操作仍可访问。引导可折叠，切换提示仍可读；讲解需要战报时自动展开。
- 训练顺序为配置、配比、指令、预览、执行。成长轨迹和五维状态默认折叠，结果保持候选而非自动应用。
- 仓库单列紧凑卡片，详细五维可展开。任务优先可领取、再进行中，已领取任务可展开。
- 失败评估保持现有逻辑，并提供前往训练的操作。

## 可访问性与验收
按钮触控高度至少 44px，具备可见焦点；支持 reduced-motion。保留 DOM id 和引导目标，折叠目标在引导时展开。新增布局契约与运行时测试，回归全部现有测试。浏览器检查 320/390/480/桌面宽度，确认敌方在上、导航不遮挡、视图切换和训练仍可用。
