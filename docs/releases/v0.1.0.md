# 魔导协议 v0.1.0 · 竖屏试玩预览版

这是《魔导协议》（Arc Protocol）的首个打包试玩版本。围绕「训练 → 评估 → 迭代」体验日志配比、核心指令、训练候选与自动战斗。

## 下载与启动

- 下载附件 **Arc-Protocol-v0.1.0.zip** 并解压，用现代浏览器打开 **index.html**。
- 不需要安装依赖、启动后端或填写 API Key；下载后可离线运行。
- 手机建议竖屏，桌面以居中竖屏区域展示。
- GitHub 自动生成的 Source code 压缩包包含整个仓库；试玩 ZIP 仅包含游戏页面和入门文档。

## 本版内容

- 竖屏战场：敌方在上、链路居中、三名队友在下。
- 作战、仓库、训练、任务四栏导航，资源与战报按需展开。
- 自动战斗与特效、失败评估、重新演算。
- 基模 / SFT、DPO、RFT / 轮次 / Benchmark 配置，日志配比、核心指令与收益预览。
- 训练候选生成与手动应用；一次性任务、手动领奖与可回看的引导。
- 协议蓝图 JSON 导出。

## 试玩提示

执行训练会消耗资源并生成候选，**不会自动切换当前能力向量**。请到仓库找到候选，点击「应用到当前协议」，再观察战斗变化。

## 预览版限制

- **没有存档：刷新或关闭页面会重置进度。**
- 基模和训练是游戏模拟，不接入真实 AI 服务。
- 尚不支持蓝图导入、跨会话离线结算与账号系统。
- 协议深度用于手动测试，尚未实现完整章节解锁流程。

## 发布验证

发布前通过现有 9 个 Node.js 测试文件，共 119 条契约检查及断言；这不等同于完整的端到端覆盖。

欢迎提交试玩反馈，附上浏览器、屏幕尺寸和复现步骤。
